# TW-home.20.06.26

# STOL PLUS

Сомонаи муосири мағозаи мебел, ки бо истифода аз **HTML**, **Tailwind CSS** сохта шудааст. Лоиҳа дорои тарҳи зебо ва қулай буда, барои муаррифии маҳсулот, категорияҳои мебел, пешниҳодҳои махсус ва маълумоти ширкат пешбинӣ шудааст.

## Имкониятҳо

- Саҳифаи асосии замонавӣ ва ҷолиб
- Қисмати Hero барои муаррифии маҳсулоти асосӣ
- Намоиши категорияҳои машҳури мебел
- Карточкаҳои маҳсулот бо нархгузорӣ
- Қисмати хабарҳо ва пешниҳодҳо
- Баннери YouTube барои муаррифии видеоҳо
- Блоки фикру мулоҳизаҳои мизоҷон
- Маълумот дар бораи ширкат
- Қисмати афзалиятҳои мағоза
- Footer бо маълумоти тамос ва навигатсия

## Технологияҳои истифодашуда

- HTML5
- Tailwind CSS
- Flexbox
- CSS Grid

## Сохтори саҳифа

- Header
- Hero Section
- Popular Categories
- Products Section
- News & Offers
- YouTube Banner
- Customer Reviews
- About Company
- Advantages Section
- Footer

## Ҳадафи лоиҳа

Ин лоиҳа барои таҷрибаомӯзӣ ва такмил додани малакаҳои Frontend таҳия шуда, тарҳи як мағозаи мебели онлайнро нишон медиҳад.
